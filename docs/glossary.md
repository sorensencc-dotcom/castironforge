# Glossary

## Harvester {#harvester}
Ingests and normalizes external data into CIC.

## Orchestrator {#orchestrator}
Coordinates agents and workflows across regions.

## Control Plane {#control-plane}
Central authority for configuration, routing, and health.

## Region Registry {#region-registry}
Tracks active regions and their capabilities.

## Telemetry {#telemetry}
Observability stream for prompts, agents, and pipelines.

## Agent {#agent}
A unit of execution within CIC.

## MCP {#mcp}
Model Control Plane integration layer.

## DLQ {#dlq}
Dead-letter queue for failed or poison messages.
