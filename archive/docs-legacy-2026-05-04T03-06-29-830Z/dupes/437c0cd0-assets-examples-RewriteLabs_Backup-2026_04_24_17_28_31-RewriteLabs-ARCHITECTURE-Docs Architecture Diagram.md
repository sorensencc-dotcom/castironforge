# Rewrite Labs — Docs Dashboard UI Mockup (Text Specification)

## 1. Overview
The Docs Dashboard provides operators with a centralized interface for navigating, searching, and managing all Rewrite Labs documentation.

## 2. Layout Structure

-----------------------------------------
|  Sidebar (Left)  |   Main Panel       |
-----------------------------------------

### Sidebar Sections
- Home
- Manuals
- Roadmaps
- Playbooks
- Templates
- Architecture
- Logs & Reports
- Versioning
- Search

### Main Panel (Dynamic)
- Document viewer
- Version info
- Quick actions
- Related documents
- Changelog preview

## 3. Quick Actions
- Open Master Manual
- Open Roadmap
- Open Outreach Playbook
- Search Docs
- View Version Manifest
- Open Changelog

## 4. Status Indicators
- Green: Up-to-date
- Yellow: Version drift
- Red: Missing changelog or unindexed file

## 5. Search Bar
- Autocomplete from INDEX.md + SITEMAP.md
- Filters:
  - Document type
  - Version
  - Subsystem
  - Last updated

## 6. Future Enhancements
- Inline diff viewer
- AI-assisted doc lookup
- Operator annotations
