# Rewrite Labs Documentation

This repository contains all operational, technical, and strategic documentation for Rewrite Labs.  
All files follow deterministic structure, operator‑grade formatting, and versioned updates.

## Structure

- **Manuals** — Canonical, organization‑wide standards and operating procedures.
- **Roadmaps** — Strategic planning documents outlining phased development.
- **Playbooks** — Tactical guides for subsystems (e.g., Outreach Automation).
- **Templates** — Reusable assets for messaging, lead profiles, and value-gap summaries.
- **Architecture** — System diagrams, API notes, and integration specs.
- **Logs & Reports** — Weekly, monthly, and quarterly operational reviews.

## Versioning

All documents follow semantic versioning:
- **MAJOR** — Structural changes or new systems
- **MINOR** — New sections, features, or expansions
- **PATCH** — Fixes, formatting, or clarifications

## Contribution Rules

- All changes must be logged in the Version Manifest.
- All new documents must include a version number and last‑updated date.
- All subsystem docs must follow operator‑grade formatting.

## Contact

For questions or updates, contact the Rewrite Labs operators.
